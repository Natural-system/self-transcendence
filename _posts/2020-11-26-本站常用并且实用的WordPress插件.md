> 这篇文章是2019年前后，我基于 WordPress网站的老文章，属于重新搬运过来，如果有些资源、信息或链接过时了，是正常现象。

基于WordPress建站除了快速之外，最吸引人的莫过于它资源丰富了，例如其中的插件是每个站长必备的，用来实现不同的功能，丰富我们的网站。下面我就介绍本站使用的6款插件，旨在实用，不搞花俏。以下的插件都可以下载，因此就不放链接了，有兴趣的站长可以自行搜索，插件也只是作了简单的介绍，想要详细了解它们的也可以网上搜索自行了解。我使用这些插件也是经过不同的技术员推荐，然后逐一试用而剩余下来继续在用的。

All-in-One WP Migration

网站备份插件，可直接把整站内容打包为后缀名为.wpress的文件（包括网站主题、评论、数据库、插件等，功能强大），适合小站站长，我个人用的是免费版，只能储存在本地，收费版本可以储存到FTP或其他网盘中，如ASW和Google cloud等等。

All-in-One WP Migration File Extension

网站恢复插件（和All-in-One WP Migration软件是最佳伴侣），在网站迁徙或需要恢复网站时，安装这个插件，把All-in-One WP Migration插件备份的.wpress后缀名文件上传即。按照提示进行释放即可，十分便捷，有中文版。需要注意的是，免费版本有200MB上传容量限制。

Author Bio Box

文章作者简介插件，用于介绍作者的个人信息，并且可以粘贴作者其他社交平台的信息，如Facebook、YouTube等。

OnePress Image Elevator

剪切和粘贴图片的插件，方便使用截图软件，并粘贴在文章内，减少了从多媒体后台上传图片的繁琐。当然，粘贴的图片会被自动上传到媒体库。

Simple Fancybox

图片灯箱效果插件，点击文章中的图片即可实现“图片模式”。

LuckyWP Table of Contents

用于创建文章目录，会自动根据文章内设置的不同级别的标题，达到自动生成目录的效果，插件也很强大，基本实现了汉化。

Really Simple SSL

强制SSL插件，在部分时候，网站在部署SSL后，有一定的可能性会导致非全站SSL，这个插件可以强制整站为SSL，十分强大。

Safe SVG

SVG格式插件，比如，本站用SVG格式LOGO，但SVG是一种编码，相较于PNG可能有风险性，这个插件可以降低风险。

tencentcloud-cos

腾讯云对象储存插件，在插件内填入相关的ID和密钥等信息，之后就可以直接在网站后台的“媒体”页面上，直接上传相关的文档、图片、视频等内容了，所有的内容是自动传入COS的。友好的是，原来储存在网站服务器中的多媒体内容，可以设置“一键转移”很方便。
